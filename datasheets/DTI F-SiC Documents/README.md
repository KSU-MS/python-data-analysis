# DTI F-SiC kit documents

Drive Train Innovation's Formula Student kit: F-MOT motors (Fischer Elektromotoren) and
the F-SiC inverter. Public on DTI's site. The numbers the sims use are in `datasheets/dti_fmot.toml`
(read by `kmslap/car/drivetrain.py`).

In git: the specifications, scope of delivery, the power-loss spreadsheet (the motor's
efficiency map comes from it), the CAN manual and DBCs, the thermal example. Kept
local (gitignored, large): the DTI CAN Tool installer (168 MB), the CAD dummies
(`*.step`, ~43 MB) and the application manuals (~15 MB).
